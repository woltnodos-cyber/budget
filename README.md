# Бюджетный трекер — Астана Edition

Полнофункциональное десктопное приложение для учёта личных и студенческих финансов, разработанное на Python с использованием графической библиотеки Tkinter и библиотеки визуализации Matplotlib.

---

## 📂 Структура проекта

* **`pusk.py`** — Главный файл графического интерфейса (GUI). Содержит реализацию главного окна, адаптивную прокрутку, таблицы категорий и истории, интерактивные формы ввода, графики, мультивалютный конвертер и кредитную систему.
* **`algorithm.py`** — Модуль бизнес-логики. Включает класс `BudgetTracker`, управление категориями и транзакциями, фильтрацию, алгоритмы сортировки, а также экспорт отчётов в консольный формат и JSON.
* **`model.py`** — Модуль структур данных. Содержит датаклассы `Category` и `Transaction`, класс для формирования отчётов `ExpenseReport`, а также пользовательские исключения (`BudgetExceededError`, `InvalidTransactionDataError`).
* **`categories.csv`** — Табличный файл с предопределёнными категориями расходов и базовыми лимитами бюджета по умолчанию.
* **`README.md`** — Полная документация проекта с описанием архитектуры, установки и возможностей.

---

## 🚀 Основные возможности

1. **Современный интерфейс на Tkinter:** Удобное разделение на панели, поддержка адаптивной прокрутки и интуитивно понятное управление.
2. **Динамический учёт бюджета:** 
   * Отображение текущего остатка средств.
   * Автоматическая смена цвета текста остатка (зелёный цвет при положительном балансе, красный при уходе в минус).
3. **Интерактивная система кредитования ("Астана Edition"):** 
   * Если средств для добавления расхода недостаточно или баланс уходит в минус, приложение выводит предупреждение с вопросом о необходимости кредита.
   * Предусмотрена многоступенчатая проверка («Вы точно уверены? Условия кредита: 50% каждый месяц»).
   * Возможность прямого пополнения общего лимита бюджета через специальную кнопку кредитования.
4. **Управление транзакциями:**
   * Добавление расходов с указанием ID, суммы, категории, описания и точной даты.
   * Возможность выбора и удаления любой транзакции из истории с мгновенным пересчётом баланса и графиков.
5. **Мультивалютный конвертер:** Мгновенный пересчёт отображаемых сумм в тенге (₸), доллары ($), евро (€) и рубли (₽).
6. **Визуализация аналитики:** Встроенные графики Matplotlib, наглядно отображающие структуру расходов по категориям.
