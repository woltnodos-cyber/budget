# ₸ Система учёта личных расходов (Астана Edition)

Современное настольное приложение на Python (`tkinter`) для удобного контроля бюджета, учёта ежедневных трат и управления финансами. Разработано с учетом локальных особенностей (валюта — тенге ₸, типичные расходы в Астане).

---

## 🚀 Основные возможности

* **Интерактивный даッシュборд:** Большой визуальный индикатор оставшегося бюджета на месяц с возможностью быстрого редактирования через иконку карандаша (`✏️`).
* **Локальные шаблоны (Астана):** Быстрое добавление частых трат в один клик:
  * 🚌 Проезд на обычном автобусе (**110 ₸**)
  * 🚀 Проезд на экспресс-автобусе (**250 ₸**)
  * ☕ Кофе с собой (**800 ₸**)
  * 🍽 Бизнес-ланч (**2000 ₸**)
* **Пополнение бюджета:** Кнопки быстрого пополнения общего баланса (`+10 000 ₸`, `+15 000 ₸`, `+20 000 ₸`).
* **Защита от будущих дат:** Умные выпадающие списки (Год, Месяц, День), которые физически не позволяют выбрать дату позже сегодняшнего дня.
* **Таблица истории в реальном времени:** Все добавленные расходы мгновенно отображаются в таблице.
* **Экспорт данных:** Выгрузка сводных отчетов в формате `JSON`.

---

## 🛠 Технологический стек

* **Язык:** Python 3.x
* **Интерфейс:** `tkinter`, `ttk`
* **Архитектура:** Модульное разделение логики (`algorithm.py`, `model.py`, `pusk.py`)
* **Автоматизация сборки:** GitHub Actions (автоматическая генерация готового исполняемого файла `.exe`)
